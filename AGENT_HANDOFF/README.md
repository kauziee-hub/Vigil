# AGENT_HANDOFF

Everything needed to switch between agents without losing context.

* `STATE.md` — start here: status, how to run/verify, invariants, open items, log.
* `prompts/00_MASTER_PROMPT.md` — the user's original brief, verbatim.
* `prompts/claude2.md`, `claude3.md`, `cursor.md`, `codex.md` — ready-to-paste role prompts.
* `outputs/` — reports produced by agents (e.g. `01_lead_report.md`).
* `REQUESTS.md` — cross-agent requests for contract/API changes.
