# Known Limitations

Every component of the demo falls in exactly one of four buckets.

## REAL (actually implemented and running)

* Payment Intent Gateway: persisted state machine with every transition logged; money moves only after approval.
* Risk evaluation across five dimensions, fusion with versioned policy, named adjustments, counterfactual.
* Interrupt ladder T0–T4; amount-scoped holds; bank release/reject; customer cancel.
* ReasonLine: deterministic customer / analyst / audit renderings; append-only decision table (DB trigger); SHA-256 integrity hash (not a signature).
* Double-entry ledger in integer paise (system total stays ₹0; customer balances never negative).
* Incremental PathGraph; RingWatch rules with evidence; post-payment monitoring that changes the next decision.
* TaintTrace using the vendored PRIMA lineage engine (LIBR + pro rata, exact conservation, 190 ported tests).
* CircuitBreaker over WebSocket to a second browser/phone; contact responses pushed back live.
* Razorpay **Test Mode** integration code: order creation via the real API and server-side payment-signature verification (HMAC-SHA256 of `order_id|payment_id`). *Requires valid test keys — the keys inherited from the PRIMA repo are rejected by Razorpay (HTTP 401) and must be replaced in `.env`.* When keys are missing or rejected, the app automatically uses the mock provider and says so.
* Benchmarks and 211 automated tests.

## SIMULATED (stand-ins for things a bank would receive from elsewhere)

* **External intelligence** — `LocalRegistryProvider` reads a local table shaped like a registry response. Labelled "SIMULATED EXTERNAL INTELLIGENCE". No DPIP, MuleHunter, I4C or DoT connection exists.
* **Call / message context** — operator-typed or scripted text, labelled "SIMULATED". Vigil cannot read calls, SMS, WhatsApp or Telegram.
* **Confirmed-scam labels** — an analyst click stands in for a verified 1930/NCRP report confirmed by the bank.
* **Bank review** — the analyst's Release/Reject buttons stand in for a fraud-ops queue; no SLA timer auto-releases holds.
* **Mule-ring transfers in Scenario 2** — injected as observed ledger postings (representing payments made before Vigil coverage), not as intents.
* **Time compression** — Scenario 3 back-dates journey events by up to 8 minutes so the story plays in seconds.
* **Mock payments** — "DEMO PAYMENT", no gateway.
* **Trusted-contact delivery** — a web page over WebSocket, not SMS/push.

## SYNTHETIC (data)

* All 142 accounts, ~2,050 historical transactions, devices and registry entries are generated by `backend/vigil/sim/seed.py` with a fixed seed. No real customer, victim or bank data.
* Thresholds and weights were hand-set to behave sensibly on this data; they are not validated on real fraud. See `MODEL_CARD.md`.

## PRODUCTION ROADMAP (not built)

* Real adapters: DPIP / MuleHunter deployment / I4C suspect registry / DoT FRI via whatever access a bank legitimately holds.
* Calibration of weights and thresholds on bank-confirmed outcomes with a temporal split; false-challenge rate as a governed metric (AdaptCal-style tuning, offline and approved).
* Authentication, authorisation, multi-tenant isolation, rate limiting (the demo API is unauthenticated and LAN-only).
* High-availability deployment, durable event stream, partitioned graph; latency SLO inside payment timeouts.
* Consent capture for trusted contacts and context signals; SMS/push delivery; localisation (Hindi and regional languages).
* Contest / re-derive workflow for TaintTrace results (designed in PRIMA docs, not built).
* PatternMemory (similarity to known ring shapes) — roadmap; the old implementation read ground truth and was not ported.
* Cross-institution tracing (value leaving the bank is reported as "left perimeter").

## Other honest caveats

* Single process, single SQLite file; designed for one demo laptop.
* `RazorpayLiveProvider` is intentionally not implemented; live keys are refused.
* Customer-facing text is English only.
* The background stream is seeded but timing-dependent; nothing in the demo depends on it.
